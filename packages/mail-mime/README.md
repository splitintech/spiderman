# Spiderman MIME transport module

MIT reusable MIME composition for Node 22.13 and Node 24, with ESM/CommonJS entry points. No provider, credential store or execution engine dependency. `buildMime` retains its date/boundary arguments and accepts an optional fourth `{idempotencyHeader}` transport setting. Header injection, reserved headers, recipient formatting and bounded attachments are validated. Campaign policy remains in the consuming product.
