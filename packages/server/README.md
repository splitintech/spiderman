# @splitin/spiderman-server

Spiderman server module: personal account connectors and agent bridge.

Development alpha `0.1.0-alpha.2`. Requires Node 24. Read the [repository setup and adapter qualification](https://github.com/splitintech/spiderman#readme) before use. Personal account ownership, approval and durable receipts are enforced by the shared core. No live provider or device qualification is claimed.
